Tools behind ForensiQ

A transparent record of how AI assistants can support planning, coding, explanation and review. The tools below are development assistants, not integrations running inside this website.

✦
✳Planning & problem solving

ChatGPT

Used as a conversational assistant to break the project into modules, reason through Flask workflows, draft code examples and explain implementation choices.

Typical contributionProject structure · Flask logic · debugging explanations · viva preparation
Example prompt

“Review this Flask digital-forensics project structure. Explain the user workflow, identify the files involved in login and evidence registration, and suggest a safe implementation plan before changing code.”

⌘Inline coding

GitHub Copilot

Used in VS Code for inline code completion, function suggestions and help while editing Python, HTML, CSS and JavaScript.

Typical contributionCode completion · route scaffolding · template snippets · refactoring ideas
Example prompt

“Add a Flask registration route using the existing MySQL helper functions. Validate the form, hash the password with Werkzeug, handle duplicate emails and follow the project's existing flash-message style.”

✧Alternative reasoning

Google Gemini

Can be used as a second opinion to review the application flow, suggest interface improvements and simplify technical explanations.

Typical contributionWorkflow review · UI ideas · documentation drafts · concept explanations
Example prompt

“Explain the end-to-end workflow of this evidence management application in beginner-friendly language. Separate authentication, evidence storage, SHA-256 verification, risk triage and chain of custody.”

✺Code review & clarity

Claude

Can be used for an independent code review, identifying edge cases and explaining long Python functions in a structured way.

Typical contributionCode review · error analysis · readability · test-case suggestions
Example prompt

“Review this evidence upload and SHA-256 verification code. Look for missing-file handling, unsafe assumptions and misleading integrity claims. List issues by severity and suggest focused fixes.”

Where AI fits in this project

Development assistants versus application functionality

DEVELOPMENT ASSISTANTSChatGPT · Copilot · Gemini · Claude

Help developers plan, write, explain and review source code during development.

FORENSIQ APPLICATION LOGICSHA-256 + rule-based triage

SHA-256 checks file consistency against a stored digest. The current risk triage scans metadata for configured keywords; it is not a trained ML model or a live API call to the assistants above.
